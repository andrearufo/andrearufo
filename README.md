### Hi, I'm Andrea 👋

Full-stack developer and software consultant from Italy. I've been building for the web since 2010.

I design and build web applications with **Laravel** and **Vue** for SMEs, startups and agencies: new products and MVPs, Progressive Web Apps, and legacy systems that need to keep running while they get better. I usually start before the code, working out what the product and the business actually need.
